Лишние повороты, стояние и стрельба в стены не устранены. Рабочие веса по результатам этих опытов не заменены.

На 16:45 активные процессы игровых прогонов и обучения не обнаружены. Последняя завершённая операция — проверенная миграция чекпоинта для следующего PPO-эксперимента. Нового PPO-обновления с геометрической головой ещё не было; её отдельный тренер пока не интегрирован.

Нейросетевые обучение и численные проверки выполняются на GPU. Реальные игры — существующим харнесом, пул до 16 инстансов, ускорение ×2.

## Что планируется дальше

1. Завершить отдельный PPO-тренер геометрической головы. PPO — Proximal Policy Optimization, обучение действий по награде за реальные бои. До первого обновления зафиксировать бюджет, скорости обучения и ограничения изменения политики.
2. Сравнить две ветки одной начальной модели: обучение всей основной политики с фиксированной доводкой и обучение основной политики вместе с доводкой. Это проверит пользу обучения нового блока по результату всего боя.
3. Собрать свежие учебные бои из текущих весов: первые 32 общие для идентичных начальных веток, следующие по 32 собственных для каждой ветки. Начальный бюджет — 96 уникальных боёв и два обновления на ветку, один динамический пул до 16 инстансов, ×2. Обучение только на GPU.
4. После фиксированного конца обучения провести до 40 оценочных боёв: S4, geometry8 до обучения, две обученные ветки и правила. Сравнить цели, смерти, попадания, движение и выбор оружия. Оценочные данные не использовать для обучения.
5. Только при убедительном результате расширять независимую проверку, затем проверять полное прохождение и живой кооператив. Если полного PPO недостаточно — следующий ограниченный опыт с реальными альтернативами движения, цели и оружия.
