# Native сетка поправок из одного состояния, 23.10.2026

Протокол фиксируется после baseline probe и до новых игр. Это целевой диагностический TRAIN опыт, не оценка победности и не PPO обучение.

Известный TRAIN seed1252025109, ware2 site01 recovery, offset109. В baseline probe до frame146 включительно входы основной политики совпали; выстрелы с category0 и category15 попали в worldspawn. В предыдущем marginal probe category16 также промахнулась. Проверяем, существует ли полезная поправка в доступной сетке25 категорий.

Создать25 копий исходной S3 с изменением только последнего слоя stateless aim head. Для category0 P0=0,999999, хвост равномерный. Для k=1..24 P0 берётся из уже закрытого TRAIN-only marginal audit S3 (около0,993260); условный хвост имеет вероятность1−23e−8 для k и1e−8 для остальных23. Все вероятности положительны, сохранён прежний frame-hash categorical sampler. Никаких runtime masks, rule aim, изменения actor/fire/RNG, training checkpoint или fitting.

До запуска на CUDA подтвердить, что записанные source Gaussian/discrete draws и прежние frame hashes дают category0 до frame146 для всех25 копий, а в frame146 дают ровно заявленную категорию. Это прогноз выбора по прежним TRAIN входам, не факт воспроизведения состояния сервером.

25 native боёв в существующем динамическом пуле до16, ×2. Одинаковый TRAIN fixture и seed, намеренное повторение. После закрытия пула: штатный native export в режиме cuda-only и CUDA finalize для всех25 моделей. Пакетная обработка с независимым состоянием каждого боя и ограниченными порциями до8, без CPU NN и fitting. Локальные копии весов диагностические, не новые production разновидности модели.

Приёмка каждого выстрела отдельно: baseline category0 должен воспроизвести прежние действия/encoded features baseline probe; остальные24 сравниваются с ним до frame146. Требуются одинаковые physical observations (служебная network identity нормализуется), encoded features, actor memory, source Gaussian/discrete draws и executed prefix. В frame146 head timing также обязан совпасть; выбранная категория должна соответствовать номеру копии. Факт стрельбы и исход берутся из эксклюзивного unrecovered first-life native provider window. При нарушении совпадения префикса конкретный случай исключается из причинного сравнения с явным указанием причины; неполный набор не объявляется доказанной сеткой25.

Один фиксированный spread/seed не оценивает ожидаемую точность и перенос на другие состояния. Даже найденная лучшая категория не назначается runtime правилом и не обучается на validation.
