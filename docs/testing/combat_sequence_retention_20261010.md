# Сохранение освоенной политики при дообучении — 10.10.2026

Предыдущий mixed curriculum дал137→136 побед на двух повторениях80
development условий, хотя смерти снизились16→14. Увеличение доли сложных
семейств не улучшило mixed Parasite/Gunner. Следующий опыт проверяет мягкое
сохранение политики на тренировочных историях остальных16 семейств.

## Обучение

Artifact: `workspace/artifacts/sequence-retention-ab-v1-20261010`.
Обе альтернативы начинают с одного сильного parent update5, с сохранением
actor/critic/log_std/Adam. Используют один уже закрытый собственный on-policy
корпус160 боёв,10953 eligible transitions. Это две альтернативные обработки
данных исходного родителя; изменённая политика не собирает второй update
по повторно использованным старым данным.

Retention spec фиксирует2392 состояния из16 тренировочных семейств.
Общий вес равный для каждого семейства, затем каждого seed внутри семейства,
затем каждого eligible состояния внутри seed. Validation данные в spec
не входят. SHA корпуса, истории, весов, train-only plan и закрытого pool
проверяются до обучения; набор members должен точно совпасть с eligible
строками retained families.

Новый KL сравнивает исходную и текущую политику на реальных историях,
включая движение, огонь, вертикальное действие, доступное оружие, доступные
цели и все условные ветки доводки. Для precision head также учитывает
coarse/fine режим. Недоступные цели и оружие не участвуют. Учитель фиксирован
перед update. Вычисления и градиенты выполняются на CUDA; FP64 применяется
для устойчивого вычитания близких распределений.

Control weight0 точно воспроизвёл исходный unregularized update: weights
SHA `59070295eb47422b873560e9aeb4b689b04009eb46a9e95845f606d7b3b1fe75`.
CUDA сравнение подтвердило точное совпадение actor/value/log_std, обоих
optimizers и RNG. Это техническая проверка воспроизводимости, не метрика
качества боя.

Candidate weight1 завершён на GPU, weights
`532fb5f55ceeade9fcf3bde552f465142225c62ca793358990ebd07953747ef0`.
Retention KL0→0.00220032 против0→0.00254091 у control. Меньший KL сам по
себе не доказывает сохранение побед или улучшение mixed боёв.

Шесть GPU численных тестов прошли: одинаковая политика, маски недоступных
действий, teacher-weighted conditional aim, target KL, precision modes,
конечность и корректность градиентов. CPU neural проверки не запускались.

## Оценка

Запущены560 native боёв: parent/control/candidate по два RNG arms ×80
условий, rules80. Один refill pool16, timescale2. Общие validation offsets
28..31,20 семейств. Это80 повторно используемых development сцен, а не480
независимых learned сцен и не финальный независимый test.

На момент этой записи evaluation process подтверждён живым, прогон идёт;
результатов качества и promotion нет. Python источники обучения заморожены
в artifact; Go/native источники текущего capture не изменяются. Опубликованные
веса и сервер человеческого кооператива не заменены.

При закрытии сравнить candidate отдельно с control и parent: парные победы,
смерти, полученный урон, native MG/Blaster попадания, задержку первого
выстрела, движение под огнём и результаты mixed/остальных семейств.
