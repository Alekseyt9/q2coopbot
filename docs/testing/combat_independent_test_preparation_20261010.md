# Подготовка независимой оценки

Широкая development-оценка остаётся основанием для выбора одного кандидата.
Отдельный test пока не запускался. Протокол: все 20 зарегистрированных
семейств, восемь неиспользованных условий на семейство, четыре варианта
(выбранный кандидат, parent3 до общей доводки, FireBC, правила), всего 640
боёв. Пул 16 с немедленным заполнением свободных слотов, timescale 2.

Выбор фиксируется до test: больше побед, затем меньше смертей, меньше
полученного урона, затем имя кандидата. Допуск требует больше побед, чем у
правил, либо столько же побед при меньшем числе смертей. Если допуск не
пройден, test сохраняется для будущей модели. После просмотра результатов
нельзя менять кандидата в рамках того же независимого сравнения.

Аудит `scripts/audit_combat_heldout_seeds.py` проверяет текущие сохранённые
pool-result/report/manifest JSON. Проверка не доказывает отсутствие внешних,
удалённых или неучтённых запусков. Активная development-оценка исключена
после проверки её замороженных validation-планов. Условия test дополнительно
связываются с SHA256 полного содержимого episode, чтобы изменение реестра
после резервирования не прошло незаметно.

Первый аудит остановился на нечитаемых отчётах старого прерванного CUDA
экспорта `aproc-v1-20261007/interrupted-m6-1791435246493051000`. Проверенный
`rollout-19/report.json` заполнен нулевыми байтами; файл сохранён без правок.
Повторный аудит пишет cache JSONL и progress, поддерживает `--resume` и
сохраняет полный список проблем до остановки.

Для таких отчётов предусмотрена узкая проверка происхождения seeds:
только нулевые отчёты offline rollout/replay в указанном старом архиве;
целые case report/manifest; совпадение seeds и native pool-member receipts;
проверка SHA256 исходных отчётов/манифестов; все строки sequence должны
содержать ровно проверенный набор seeds. Это восстанавливает только учёт
использования seeds, не качество повреждённого отчёта и не пригодность
старой модели. Произвольные повреждённые capture-файлы не исключаются.

Живая проверка rollout-19: 498 строк, seeds 1725048..1725051; все источники
совпали. Четыре теста прошли: корректное происхождение, отказ для чужого
seed, изменённого исходного receipt и ненулевого повреждённого отчёта.
Нейросеть в этих проверках не исполняется.

8 784 452 497 байт. Все выбранные файлы имеют атрибут Compressed; SHA256
