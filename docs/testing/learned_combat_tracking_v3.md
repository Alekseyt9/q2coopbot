# Blaster tracking: отдельные метки учителя v3

05.10.2026. После отрицательного прямого прогона BC v1 добавлен `teacher_tracking_candidates_v3`. Он расширяет подражание наведению и огню Blaster. Это не обучение выбору оружия и не PPO.

## Качество и проверка

Capture дополнен teacher_aim_source и teacher_aim_entity. Они записываются из фактически исполняемого контроллера правил, только при отсутствии прямого provider control. Это metadata источника метки, не признаки сети. Прежние трассы без этих полей остаются пригодны для v1/v2, но не получают новые tracking-метки задним числом.

V3 наследует проверки первой жизни, непрерывного native-перехода и точной отправленной команды, отсутствия corrections/guards, смерти, полученного/self/friendly урона. Дополнительно требуются неизменный Blaster, отсутствие запроса смены, source enemy, ненулевой ID цели, совпадение с наблюдаемым enemy и clear_shot=true. Метки aim/attack повторяют реальную команду правил, в том числе их условие отпускания кнопки. Для стоящего на земле неприсевшего учителя с отпусканием up также размечается vertical release. Наземное движение по-прежнему требует реального смещения ≥2.

Tracking не требует попадания в том же tick: у Blaster снаряд летит с задержкой. Нельзя приписывать поздний урон текущему повороту. Качество явно помечено `teacher_tracking_convention; unreviewed; not projectile hit attribution or tactical acceptance`. Это расширение BC, а не доказательство оптимальности учителя. Targetless attack release наследуется из v2; старые selectors не изменены.

Тесты проверяют наблюдаемую цель и отклоняют чужой ID, отсутствие цели, source route, guard и provider-owned frame; поздний projectile damage не исправляет отсутствие доказательства цели. Проверено сохранение поведения v2.

## Следующий ограниченный BC

Следующий пилот специализируется на Blaster: новый tracking v3 + прежний отдельно маркированный vertical primitive v1. Старые movement/mixed и Shotgun aim-наборы не добавляются: у них нет полного покрытия прицела для данного оружия. Feature/action контракт и 64×64 MLP остаются прежними. Гиперпараметры BC v1 сохраняются заранее: 300 шагов Adam, lr 0.001, seed 20261005, фиксированная финальная эпоха. Результат test не используется для подбора. Разделение по seed в одинаковой геометрии не доказывает перенос; данных на состояниях собственной политики пока нет.

Выбор оружия может обучаться с нуля через RL без демонстраций. Для этого пока отсутствуют обучаемая голова выбора, маска доступного инвентаря, policy/value PPO и опыт исследования разных оружий с отложенными эффектами. Положительные результаты фиксированного Blaster не заменят эту проверку.

Все первые жизни BC v2 закончились смертью, у rules — конец трассы. Gameplay rules 4/4, BC v2 0/4. В отличие от прошлого v1 сеть теперь наносит Blaster-урон, но это сравнение разных наборов seed и не доказательство статистического улучшения. Пилот остаётся непригодным для замены rules.

Во всех жизнях v2 владел 1052 кадрами. Candidate attack=true 1049 кадров. Vertical: release 1004, crouch 48, jump 0. Guards: static_hull_blocked 690, protocol_pitch_limit 425, unsupported_motion_guard 12; один кадр может иметь несколько причин. Selection p99 523–527 мкс. Сеть часто упирается в препятствия и отклоняет прицел; нужны обучение на собственных состояниях и отдельная оценка. Данные с плохим исходом не становятся положительными демонстрациями.

Сравнение `workspace/artifacts/combat-bc-weights-blaster-v2-20261005/direct-comparison.json`, подробный аудит рядом `direct-command-audit.json`. Собственные процессы завершены, порты освобождены, пользовательский live не переключался.

Следующий R4b должен добавить stochastic policy/value и PPO на свежих rollout своей версии, с фиксацией намерения/guarded исполнения и версий весов. Демо не являются обязательным условием RL; можно сравнивать BC→RL с RL с нуля. Для оружия нужен самостоятельный эксперимент с головой выбора и доступным инвентарём; нынешний fixed Blaster это не проверяет. Дополнительные teacher corrections остаются отдельным вариантом, а не обязательной заменой RL.
