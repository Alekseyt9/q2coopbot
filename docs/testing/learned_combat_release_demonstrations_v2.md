# Метки отпускания огня System 1 v2

Дата: 05.10.2026. Добавлен отбор `teacher_candidates_v2`: 36 положительных Shotgun aim/attack и 216 отрицательных attack/release на новом сборе. Веса и оптимизатор не создавались.

## Правило и границы

V1 сохранён как отдельная версия; его фильтр и замороженные данные не изменялись. V2 сохраняет правила положительных компонентов и добавляет только маску attack для правила учителя «нет наблюдаемой цели — отпустить огонь».

Для отрицательной метки нужны rules без fallback, первая жизнь, живой бот, свежие соседние наблюдения, геометрия, точный native dispatch/tick и доступные эффекты. В обоих наблюдениях нет наблюдаемых врагов; proposed/action/applied не требуют attack, фактически отправленная кнопка выключена, оружие не меняется, запроса смены нет. Исключаются любые ограничители/коррекции, урон/смерть, положительный урон монстрам и любые outgoing take-события от бота, включая трупы. Для сокращения повторов выбирается каждый десятый индекс перехода в эпизоде. Только attack получает положительную маску обучения; движение, aim, vertical и weapon выключены.

Это явно записанная конвенция учителя, а не доказательство оптимальности отказа от слепого/предсказательного огня. Пустой список наблюдений не означает отсутствие скрытых врагов. Setup/barrier/death не считаются полезными отпусканиями. Подавление огня рядом с напарником/бочкой и во время cooldown пока не размечено. Серверные эффекты используются только для проверки/диагностики, не добавляются в observation.

Текущий learned-пилот передаёт управление rules при отсутствии наблюдаемого врага. Поэтому эти метки описывают offline-границу огня; live-управление обученной головой release ещё не подтверждено.

## Сбор

Оружие фиксирует test-only fixture, помощь учителю записана в source. Новых изменений native/игрового управления в этом шаге нет.
