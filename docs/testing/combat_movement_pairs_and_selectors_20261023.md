## Решение

Ни один модуль не выбран. Не продолжать эти fits, не менять их пороги и не запускать дорогую quality серию отклонённых endpoints. Новых игр после fitting не было; рабочий default прежний. Коммитов/push мной не выполнялось.

Следующая гипотеза должна различать две ещё не установленные причины: замороженное представление старой политики может плохо сохранять признаки полезного манёвра, а дальний исход после одного короткого вмешательства может давать шумную метку. Следующий ограниченный шаг — TRAIN-only разбор краткосрочных физических последствий из уже принятых захватов (движение, сближение parasite, ближайший полученный урон) и сопоставление с конечной utility. После него отдельно зафиксировать опыт с явными относительными геометрическими признаками/другим горизонтом либо проверку устойчивости меток. Не объявлять причину установленной по одному провалившемуся fit и не расширять бессистемно прежний PPO.
