Reset действует только с root+1. Проверены точные наблюдения, команды и выборки до reset; совпадение полного admitted first-life baseline с matching clamp; соответствие историческим root features/source latent. CUDA подтверждает Gaussian, final-fire и category/wide CDF; фактические Gaussian потоки двух forks различаются.

## Короткий bootstrap: проведён reuse-only CUDA probe

`probe_combat_wide_horizon_cuda.py` завершил `combat-wide-horizon-uncertainty-v2-20261026/report.json`. Использованы только те же 112 choice-ветвей с CUDA-verified next_value; новых боёв, нейросетевого fitting и actor weights нет. Расчёт n-step суммы и агрегатов выполнен CUDA float64. Аналитические CUDA regressions проверяют reward+bootstrap, terminal zero, незавершённое окно и разрыв кадров. Исходники, модели, rollout и proof связаны SHA до/после обработки.

Для горизонта h суммируются наблюдаемые награды до root+h, затем добавляется source critic next_value с соответствующим дисконтом. При terminal zero bootstrap отсутствует; незавершённое или разорванное короткое окно остаётся missing. Конечная наблюдаемая сумма сохраняет все исходные admitted rows, включая ownership gaps, и сверяется с прежним full-return contrast. Первая версия v1 ошибочно требовала непрерывность и для конечной суммы и оставляла bunk1 missing; её отчёт и исходник сохранены отдельно, v2 исправляет только этот случай.

Здесь приведены только пять контекстов без full-life hybrid streams. Все восемь, включая city2/bunk1/waste3, остаются в JSON с явным hybrid count. Значения h=1 почти не имеют stream variance **по построению**: RNG reset начинается на root+1. Это не доказательство качественного critic. В двух наблюдаемых ничейных контекстах h=1 создаёт предпочтение выше порога .05; на ware1 знак среднего h=16 отличается от конечного семипоточного среднего. Нельзя автоматически заменить single-pair labels коротким critic bootstrap. Более длинные горизонты тоже не объявляются победителями по этой reused выборке.

Вывод для следующего обучения: single-pair hard label недостаточна; необходимо сохранять несколько paired continuations, величину/разброс преимущества, ничьи и ownership, а не только бинарный победивший выбор. Семь продолжений восьми TRAIN состояний остаются диагностикой; новые обучающие targets пока не выпущены. Перед расширением сбора стоит ускорить preflight: повторная проверка этих 96 планов через два `go run q2episode` на план заняла около 292 с до старта серверов, при сохранении того же CLI можно переиспользовать собранный исполняемый файл и сохранить SHA-проверки.
