# Direct native-effect prediction pilot: rejected

Artifacts: `workspace/artifacts/hjepa-effects-fit-v1-20261116`.
The protocol was fixed before fitting. Producer targets retain the prior48/16
source-world partition, with no validation/test data used for optimization.
Trainer: `scripts/train_combat_hjepa_effects.py`.

At each horizon1/4/16, the state is the corresponding frozen H-JEPA32-dimensional
latent plus26 observed equipped/own-previous-request features. Latent mean/scale
are estimated only from fit worlds. Commands carry20 values per future tick.
Each predictor is a64-unit ReLU layer followed by six linear effect outputs.
The full and action-ablated variants have identical parameter counts, initial
weights, minibatch orders and fixed100-epoch Adam1e-3 budgets. The ablated variant
receives zeros in all command positions. Utility, motor and weapon heads are
unchanged. No fitting of encoders, checkpoint choice or coefficient sweep.

Both predefined criteria fail: horizon16 full-command reward error does not beat
the action-ablated and fit-mean baselines by10 percent, and full-command effect
MSE exceeds the fit-mean baseline at every horizon. Horizon16 fit effect MSE is
0.001426 but holdout error is0.016906, consistent with substantial overfitting.
Equal-world averaging also leaves full-command reward error above the fit-mean
baseline at every horizon. No neural forecast here is accepted for integration.

Windows overlap and are not independent combat trials. Observed future commands
were generated by a policy reacting to future observations; their association
with effects is not proof of causal action rankings. These data do not isolate
whether the limiting factor is source coverage, fixed encoder information loss,
model capacity, sparse terminal effects or insufficient action contrasts.

The exported model is an offline predictor bundle, not a Go runtime controller.
No native evaluation or promotion followed the failed gate. Reserved external
VALIDATION442 remains unplayed, U1 unchanged, general combat goal still open.
Next investigate controlled action contrasts and frozen encoder information
before another fit; do not tune this model against the same16 holdout worlds.
