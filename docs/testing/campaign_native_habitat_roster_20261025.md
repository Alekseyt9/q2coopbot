# Случайные группы с разными корпусами и средами

Проверено 25.10.2026. Генератор `campaign-native-habitat-roster-v1` объединяет stock-профили монстров, случайные дополнительные составы и неполный инвентарь.

```powershell
go run ./cmd/q2episode --root . --all-map-sites 1 --native-habitat-roster --out <fresh-catalog.json>
```

Основной тип берётся из исходного профильного сценария карты. Дополнительные типы и количество выбираются по seed с повторениями; пул содержит только точные классы из исходного BSP. Для каждого дополнительного класса `additional_by_class` хранит отдельные позиции, проверенные по его корпусу и среде. Вода не заменяется сухим полом; летающий тип не проверяется как стоящий игрок. Для дополнительных акторов также исключено пересечение с исходными местами входа игроков.

Потоки состава, размещения и инвентаря разделены. Старый ground-roster v1 и его семена сохранены. Новая версия распределения состава — `version=2`, с явным `primary_class`; диапазон семян новой семьи начинается с 1,82 млрд и отделён от профильных одиночных рецептов и старых семейств. Описание эпизода содержит полный возможный пул; экземпляр плана — фактически выбранных монстров.

Геометрия резервирует до четырёх акторов. Если 16 заранее заданных семян каждого split не проходят размещение максимальной группы, предел последовательно снижается. Это техническая проверка до исходов игры, не отбор по победам. При невозможности группы явно сохраняется одиночный рецепт с пустым дополнительным пулом; флаг `mixed` соответствует этому пределу.

Каталог содержит 204 рецепта на 38 картах: 175 с максимумом 4, 10 с максимумом 3, 15 с максимумом 2 и 4 одиночных. `fact3` не получает искусственных монстров. Неподходящие пары «карта–тип» остаются в `profile_missing`.

## Живая проверка

Артефакты: `workspace/artifacts/combat-native-habitat-roster-v1-20261025/`.

До просмотра исходов выбраны первые рецепты каждой карты и каждого основного типа, по первому seed: 53 боя, pool16, x2. Результат: 53/53 валидных capture, исходники не менялись, 4998 игровых кадров, время пула 123,83 с.

- 38 карт, 21 боевой тип из исходных BSP.
- 145 подтверждённых native акторов: 25 групп по два, 17 по три, 11 по четыре.
- 20 групп с повторяющимися типами, 25 с разными средами; одна группа содержит все три среды.
- Проверены точные классы/ID/количество/здоровье/позиции, BSP SHA, наблюдаемый inventory reset и выполнение команд без recovery-команд.
- Для 140 из 145 акторов на начальном кадре доступен сетевой bbox; все соответствуют stock-профилям с native-квантованием. Остальные пять не объявляются наблюдавшимися: их старт подтверждён серверной записью, а корпуса соответствующих типов ранее проверены отдельно.

Доказательства: `pool/report.json`, `habitat-roster-verification.json`, `audit.py`, frozen plan/registry, исходные записи. Проверки `internal/trainingepisodes` и регрессии завершения для повторяющихся типов прошли; CLI и бот скомпилированы.

Последующая проверка закрыла нативное завершение цели с воскрешением Medic и преемником Jorg; 204 новых рецепта добавлены в главный реестр. Доказательства и отдельное ограничение CUDA-тренера описаны в [проверке жизненного цикла](campaign_native_objective_20261025.md). NN-обучение и переключение рабочих весов не выполнялись.
