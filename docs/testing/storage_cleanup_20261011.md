# Очистка старых прогонов, 11 октября 2026

По запросу пользователя удаляются старые объёмные данные из `workspace/artifacts`, с целью освободить 100 GiB фактически занятого места.

Удаляемые файлы: JSONL с кадрами и промежуточными экспортами, отдельные копии модели `provider-worker-*.json` для каждого эпизода, старые исполняемые файлы, демо, журналы и Python bytecode. Папки не удаляются целиком: основные JSON с весами, PT-чекпоинты, отчёты, планы и скрипты остаются.

Последние эксперименты shared target от 11 октября, текущие линии обучения decision/group/pair, сравнения с rules и anchor/bank исключены из очистки. Исходники, опубликованные модели, игровые ресурсы и работающий кооперативный сервер не затрагиваются.

После удаления старые отчёты сохраняют результаты, но повторно обработать удалённые записи кадров уже нельзя. Для новых экспериментов следует генерировать новые бои по сохранённым рецептам реестра; сохранённые чекпоинты пригодны для продолжения обучения.

Точные пути и изменение свободного места записываются в `workspace/artifacts/cleanup-old-runs-receipt-20261011.json`. Скрипт `workspace/artifacts/cleanup-old-runs-20261011.ps1` проверяет границы путей и активные процессы, не обходит каталоги junction и прекращает очистку после достижения цели. Сумма длин файлов не используется как оценка освобождённого места: учитывается реальное свободное пространство диска F.

Очистка завершена: удалено 278 048 файлов в 33 старых сериях. Реальное свободное место увеличилось на 107 619 987 456 байт, то есть **100,23 GiB**. На момент итоговой проверки свободно **114,53 GiB**; небольшая разница с финальным значением в receipt объясняется записью отчётов и метаданных после измерения.

Проверены SHA-256 шести файлов текущих моделей: веса и чекпоинты reference update 9, shared target update 10 и control update 10 не изменились. Все шесть отслеживаемых Git файлов в `models/` на месте. Работающие сервер и Go-бот (PID 1976 и 3556) сохранены.

В каждой очищенной серии оставлен `bulk-cleanup-20261011.json`, чтобы удалённые данные не выглядели как полный доступный корпус. Очистка остановилась при достижении цели.
