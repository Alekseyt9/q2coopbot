Это описательный диагноз траекторий, не доказательство единственной причины различий.

## Следующее решение

Не масштабировать этот узкий gaze/fire fit и не увеличивать сеть ради результата на офлайн-метрике. Сохранить исходный Geometry8 как контроль. Следующая проверка должна охватывать **возвращение линии огня через перемещение**, включая устаревшую память и завершение цели, а не только взгляд на последнюю точку. Использовать отдельно назначенные TRAIN-миры; эти validation-бои остаются только диагностикой. Сначала небольшой пилот причинных перемещений после потери контакта на четырёх картах с неизменными прицеливанием/огнём источника и полным исходом боя; затем при наличии воспроизводимого сигнала собирать обучающие ветви с отдельными мирами development. Не использовать краткий урон/простую близость к последней точке как замену победе: прежний under-fire H10 пилот уже показал такую ловушку. Исходный контроль, нулевая интервенция, одинаковое прошлое до развилки и независимые будущие потоки обязательны для отделения эффекта действия от случайности.
