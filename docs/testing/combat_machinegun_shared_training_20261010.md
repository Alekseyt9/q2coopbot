# Общая обучаемая доводка автомата и бластера

Нативный разбор32 диагностических боёв показал589 выстрелов PPO с явно
выбранной доступной целью. Средняя угловая ошибка до отдачи21.29°, после
23.95°; отдача ухудшила её больше чем на1° в300 случаях. При отдаче>6°
ошибка20.48→24.26°, signed pitch error3.49→−8.94°. Сравниваются реальные
native view/aim и наблюдаемая до команды bbox-точка цели; её движение,
давность снимка, препятствия и случайный разброс не устранены. Это
диагностика, не причинный эксперимент.153 выстрела не имели объявленной
цели, правила тоже её не объявляют и по этому показателю не измеряются.

Установлено по коду: прежние метки targeted/postmove прицеливания исключают
автомат, поскольку свежая отдача оружия не равна наблюдаемой camera kick.
Её нельзя просто объявить известной по предыдущему kick_angles_degrees.

Добавлен контракт `combat_shared_spatial_coarse_fine_aim_v2`: общая ветка
119→64→32→6. Первые4 выхода сохраняют fine/mode v1, новые2 исправляют
coarse yaw/pitch для каждого из восьми наблюдаемых targets. Признаки прежние:
дистанция, bbox, относительные скорость/направление, наблюдаемая отдача,
оружие, движение, запланированное среднее движение базовой сети. Нативная
отдача и будущая позиция ствола не становятся признаками.

Миграция всех8 архитектурных priors и контрольной PPO parent3 прошла CUDA:
нулевой coarse residual сохраняет существующие выходы; отдельно проверено
соответствие новых выходов coarse-парам. Go проверял только размерности
контракта, нейронные численные проверки выполнялись на CUDA. Клиент и
компилятор эпизодов пересобраны. Старый4-выходный контракт также принимается.

Собраны96/96 валидных боёв, pool16 ×2:80 свежих own-policy train136..139
по20семействам,16 development-validation28..31 по четырём пилотным
семействам. Общий корпус посещений собирала замороженная parent3 после
сохраняющей поведение миграции. Это общий BC-bootstrap, не собственный
PPO-корпус каждого из восьми других priors. Финальные test seeds не тронуты.

Для каждого фактического выстрела автомата офлайн метка использует нативные
muzzle/fresh recoil и текущие клиентские точки всех доступных целей.
Она условна относительно исполненной стрельбы/движения; случайная свежая
yaw-отдача вносит шум. Скрытые позиции врагов не используются. Прежние
postmove-метки бластера сохранены. Исходные признаки/identity/seed/index
проверены поэлементно:6580 train и1398 validation строк совпали с клиентским
экспортом. Для train1549 пар автомата,3513 бластера; validation693 и895.
Списки seed разделены; reward/hit credit метки не изменяют.
