# Shared aim: подтверждение преимущества не получено

23 октября 2026. Независимая серия завершена: **96 игровых боёв и 72 CUDA-проверки**. Новая сеть доводки не прошла заранее заданные критерии. Основные веса не заменены; более широкая оценка этого кандидата не запускается.

## Техническая приёмка и восстановление

Все96исходных игровых captures сохранены, повторных игр не было. Для72learned captures закрыты CUDA likelihood/value/memory/transform проверки. Уshared778eligible кадров с проверкой всего вектора25live logits, а не только выбранной категории. Source/model hashes сохранены, обучения по validation не выполнялось.

Первичная обработка остановилась на третьем source случае: float32 critic value error0,0001092 превышала прежний порог0,0001. Расчёт того же критика и исходных JSON features наCUDA float64 дал ошибку4,09e−14; память критика совпала до7,33e−15. Порог не ослаблялся. В finalize добавлен float64 fallback только для такого расхождения; actor/действия/игровые веса не меняются. Контекст при fallback создаётся заново из JSON, а не из округлённых float32 данных.

Новый resume coordinator повторно использовал закрытые CUDA cases и восстановил только недостающую обработку. Исходные failure progress/logs сохранены, финальная квитанция помечена cuda_postprocessing_recovery=true. Это техническое восстановление, не новая оценка качества.

## Проверка другой учебной цели

После закрытия серии проведён отдельный фиксированный GPU опыт по [предварительному протоколу](../combat_return_teacher_protocol_20261023.md). Две одинаковые сети shared191→16→1 получили по500шагов, отличалась только метка: immediate HP либо остаток sparse reward до конца боя. Использованы26ранее принятых one-frame состояний:14train/7seed и12development/6seed; validation/confirmation в обучение не включались. Старые17constant-head состояний исключены, поскольку вмешательство в них могло повториться позже.

| На12development состояниях | Immediate teacher | Sparse-return teacher | Constant для return teacher |
|---|---:|---:|---:|
| Масса известных действий с улучшением sparse return≥1 |1,980%|2,564%|2,471%|
| Масса известных действий с ухудшением sparse return≥1 |0,748%|1,131%|1,521%|
| Вклад известных действий в sparse delta |0,1240|0,1480|0,0291|

Return teacher не прошёл допуск: прибавка полезной массы к constant лишь0,093п.п.; прибавка известного return к matched immediate около0,024вместо требуемых0,10. Положительный вклад только известных действий не является ожидаемым return всейполитики. Одиночные продолжения дают шумные метки. Новые native игры этих прототипов не запускались.

## Дальше

Не продлевать эти fits и не менять пороги. Следующий ограниченный этап — расширить число независимых TRAIN состояний и поддержать одно вмешательство на фоне обычной действующей политики. Нынешний one-frame probe требует постоянную baseline голову, а успешное обучение меняет дальнейшее распределение состояний; это возможное ограничение, пока не доказанная причина провала. Новому контракту нужны воспроизведение обычного baseline, сохранение всех прочих действий/RNG, запрет обычного PPO для диагностических captures и полная native/CUDA приёмка. Затем собрать новые парные метки и сравнить учебные цели на более широком наборе с разделением по целым сидам. Default остаётся прежним.
