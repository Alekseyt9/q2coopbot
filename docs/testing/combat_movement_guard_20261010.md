Изменения Go:

- Боевой прогноз учитывает запрошенное приседание в текущем тике; при
  отпускании использует стоячую скорость как консервативную верхнюю оценку.
- Проверка двери использует расчетный путь текущей команды вместо
  фиксированного40-unit направления независимо от скорости.
- Для наблюдаемой заблокированной двери пробуются только исходные
  составляющие команды. Удаляется одна составляющая, новая не создается.
- Кандидат заново проверяется на static hull, поддержку, дверь и лазеры.
  Неизвестная дверь, прыжок, воздушное движение и ненулевой опасный остаточный
  импульс не получают разрешение через этот механизм.
- При безопасном сокращении сохраняются приседание, yaw/pitch и attack.
  Проверки геометрии оставляют стоячий hull: прохождение под низким потолком
  этим изменением не разрешается. Это ограничитель исполнения, не новый
  выбор тактики, автонаведение или штраф reward.
