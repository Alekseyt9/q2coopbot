# Расширенная проверка Mixed control, 07.10.2026

**Последующий отдельный опыт:** [expanded Mixed batch](learned_combat_mobile_mixed_expanded_v1.md) возобновил Adam от16 и использовал64 новых training episodes. Его кандидат получил10/32 побед против4/32 parent и выбран для дальнейшей проверки. Это другой checkpoint; отклонённый fresh-Adam control из настоящего отчёта не был повторно принят.

Кандидат control−5 из death-penalty compare **не заменяет checkpoint16**. На32 новых paired Mixed seeds он получил2 полные победы против3 у parent,30 смертей против28 и10 убийств против11. Небольшой выигрыш3→1 на предыдущей16-seed выборке не подтвердился на новой. Это достаточная причина не принимать кандидата по заранее записанному протоколу, но не доказательство статистически установленной худшей политики.

## Условия и проверка

Сиды39000–39031,32 эпизода на модель,64 native captures. На каждом из четырёх инстансов восемь независимых эпизодов со своим seed; кандидату и parent выдаётся одинаковая последовательность seed. Модели выполнялись последовательно, максимум4 сервера/клиента, x2. Использован существующий `run_learned_combat_baseline.ps1`. Stock Machinegun100 bullets, skill1, stock monster HP, spawn z24.125, release100, максимум300 active frames, native no-infighting с исправленным dead-owner grenade splash и ранняя остановка после двух подтверждённых убийств на первой жизни.

Обе сети зафиксированы, для оценки включён deterministic output. Actor/critic weights не обновлялись, оптимизация ни на GPU, ни на CPU не запускалась. Parent — checkpoint16 curriculum; candidate — четыре fresh-Adam CUDA updates control−5 от него. Сиды новой оценки не входили в обучение или предыдущие оценки этих веток. Исторические captures не пересобирались.

Аудит принял64/64 захвата: native seed/reset/dispatch provenance, одинаковые исходники между моделями, модельные SHA, состав Mixed, отсутствие урона живому монстру от другого монстра, минимум две горизонтальные позиции каждого класса в trace. Goal receipts согласованы с обеими native kills и положительным HP первой жизни; living terminal имеет death reward0 и kill reward не менее10. Все failed episodes достигли300 active frames. Полная engine/AI детерминированность и unseen/general combat acceptance не заявляются.

## Решение и дальнейшее обучение

`selection.json` отменяет только предварительный выбор training candidate из death compare. Исторический16-seed результат сохранён, рядом с ним добавлен `followup-selection.json`. Текущий training baseline снова checkpoint16; штраф за смерть−5, сеть Temporal attention, fixed MG. Live/default policy не переключена. Выбор оружия этой оценкой не проверялся.

Следующий этап — новые on-policy Mixed batches от checkpoint16 с GPU-only оптимизацией и более широким учебным набором. Новую оценочную выборку снова держать отдельно; не обучаться на39000–39031 и не использовать их для подбора награды. Сначала улучшать завершение группы/выживание, затем оценивать прицел как вспомогательную метрику. Более сильный death penalty и увеличение сети без отдельного опыта не подтверждены.
