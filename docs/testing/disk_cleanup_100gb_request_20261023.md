# Очистка по новому запросу 100 ГБ, 23.10.2026

Освобождено **33,63 ГБ (31,32 ГиБ)** по изменению свободного места F:. После проверки свободно **255,47 ГБ (237,92 ГиБ)**. Цель дополнительных 100 ГБ не достигнута. Это отдельная операция; результаты предыдущих очисток сюда не прибавлялись.

Удалено 10 890 файлов: примерно 15,19 ГиБ воспроизводимого кэша ядер CUDA и 15,61 ГиБ трасс исторических прогонов до 23 октября. Расхождение с изменением свободного места включает метаданные NTFS и возможные сторонние изменения тома.

Сохранены все веса, чекпоинты, predictor-файлы, отчёты, рецепты, реестры, демки, игровые ресурсы, все артефакты 23 октября и исходные корпуса из актуального реестра предсказания выстрела. Контрольные суммы 1555 сохраняемых файлов совпали до и после очистки. В их числе веса/чекпоинты и потоки защищённых исходных корпусов. Новые игровые и нейросетевые вычисления не запускались.

Старые удалённые трассы больше недоступны для подробного повторного анализа. Для них потребуется новый захват; исторические сводные отчёты сохранены. Затронутые корни содержат `historical-retention-100gb-20261023.json`.

Удаление выполнено по явным путям только внутри `q2coopbot-src/workspace`. Перед каждым удалением проверялись границы, отсутствие reparse ancestors, тип файла, длина и время изменения. Для многоссылочной трассы удалялись только группы, у которых все NTFS hardlinks входили в набор истёкшего хранения; группы с сохранённой или внешней ссылкой не удалялись. Рекурсивного удаления каталогов не было. Сверка подтвердила соответствие всех удалений плану и отсутствие указанных файлов.

Полное дерево `F:/src/quake2` перед удалением оценено в **103,41 ГиБ** реально выделенных данных обычных уникальных файлов. Это оценка без повторного учёта hardlinks и без обхода целей символических ссылок, не сумма размеров папок. Первичный `physical-summary.json` ошибочно учитывал цели файловых symlinks AAS повторно; его заменяет **`physical-corrected.json`**. AAS уже используют общий набор: ресурсы не изменялись и не сжимались. Исходный логический обход охватил 1 617 065 имён, ошибок чтения не было.

Таким образом, оставшуюся цель 100 ГБ нельзя получить из этого дерева с сохранением текущей работы. Другие проекты, программы, игры и личные файлы F: не удалялись. Большая часть общего занятого пространства тома находится вне этого дерева.

Аудит: `workspace/artifacts/disk-cleanup-100gb-20261023/` — `plan.json`, `receipt.jsonl`, `complete.json`, `physical-corrected.json`, `retained-before.json`, `retained-after.json`, скрипты удаления и проверки. Коммиты и push не выполнялись.
