## Итоговый отчёт

`scripts/report_registered_combat_comparison.py --evaluation OUTPUT --spec SPEC --out FRESH_REPORT` принимает только полный evaluation seal. Проверяет SHA spec/pool/paired comparisons, одинаковые fixtures, индексы контроллеров, правильный network-clock v4, связь behavior с damage и повторный SHA входов. Сводит каждый контроллер и парные изменения all/ordinary/recovery, плюс switches/turns/standing/targetless attack; нейронное вычисление и обучение отсутствуют. Family bootstrap описательный, не acceptance gate. Проверка арифметики по8 реальным закрытым comparisons/896 paired rows дала точное совпадение с первой factor analysis; дубликаты отвергаются. Полный CLI нового reporter будет проверен после настоящего smoke seal. Очередь `report-target-commitment-cumulative-20261011.py` ждёт smoke-v4 и затем quality-v2, сохраняя отдельные report outputs; незавершённые/failed evaluations не публикуются как результат.
