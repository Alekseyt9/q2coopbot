## Версионированное воспроизведение

Добавлен отдельный diagnostic continuation version `combat_post_movement_window_rng_fork_v2`. Он допускает только v13 memory/static-route joint-candidate policy без wide, с явно заданным movement window длиной2–10кадров и fork ровно после полного окна. Старый `combat_policy_continuation_rng_fork_v1` и его legacy/wide правила сохранены. Версия receipt берётся из заголовка, а не подставляется константой v1.

Go metadata/PRNG/receipt tests проверяют admission, fork position, завершение окна, overflow, несовместимые diagnostics, запрет ordinary PPO и отсутствие сброса RNG внутри манёвра. Python metadata tests проверяют ту же границу. Эти тесты не конструируют neural network и не выполняют CPU neural inference. Численная проверка политик — CUDA.

После одинаковых source/back манёвров в374–378 меняется только дальнейший policy RNG с кадра379. Три seed заранее зафиксированы:2026102631/2632/2633, общий seed внутри каждой пары. Исходный engine seed1847002396 сохраняется; это три будущих потока одного мира, не три независимые карты или мира.

Дополнительный `audit_combat_option_credit_cuda.py` / `combat-option-credit-audit-v1-20261026` воспроизводит GAE при gamma0.99 и lambda0.95 со stored critic bootstrap, соблюдая terminal/truncation. Простая замена lambda не выбрана как следующее исправление.

Сдвиг forward mean−1 равен−4.37966σ при std0.22833. Суммарный movement marginal KL пяти таких кадров47.95354nats; наблюдённый log density ratio shifted/base38.60893. Это мера отличия исследованного манёвра от обычного сэмплирования на этих состояниях, не вероятность полезного поведения. Она мотивирует отдельную гипотезу обучаемого выбора коротких согласованных манёвров; не доказывает, что новая архитектура выиграет.

Новые actor weights не обучались, default не менялся и diagnostic validation записи не стали TRAIN. Следующая проверяемая архитектурная гипотеза и её критерии ведутся в Hindsight: learned temporal movement options, с нулевой совместимостью, совместной likelihood движения/прицела/огня, отдельным typed optimizer/checkpoint и fresh TRAIN. Frozen source и такой же статический exploration должны быть отдельными контролями.
