# Сайт прогонов Go-бота

Запуск из Windows CMD:

```bat
cd /d F:\src\quake2\q2coopbot-src
start-runs.cmd
```

Открыть http://127.0.0.1:18791. Другой порт: `start-runs.cmd 18792`.
Повторный запуск распознаёт уже работающий Run Explorer, печатает его адрес
и ждёт нажатия клавиши, чтобы окно при двойном клике не закрывалось сразу.
Остановка: Ctrl+C в окне CMD. Скрипт собирает Go-сервер с встроенным интерфейсом;
Node.js и npm для запуска не нужны.

Таблица загружает по 25 прогонов. Сортировка — время изменения JSONL,
новейшие сверху; это время последней записи файла, а не гарантированное время
начала прогона. Карта в таблице — первая карта в трейсе. В просмотре можно
выбрать любую карту, встречающуюся в прогоне. Поиск по карте и пути работает
по всему каталогу, страницы загружаются с сервера. «Обновить список» перечитывает
данные; каталог на сервере кэшируется на 10 секунд. Повторный выбор прогона
перечитывает его координаты, включая дописанные наблюдения.

Источники по умолчанию: `workspace/artifacts/**/*.jsonl`, BSP/PAK из
`../assets/baseq2`, текущего подготовленного runtime и reference BSP.
JSONL без `map` и `self` не включаются в таблицу. Повреждённые строки
пропускаются с сообщением; максимальный размер трейса — 256 МиБ.

След бота меняет цвет по здоровью в каждом наблюдении: 100 HP — зелёный,
50 HP — жёлтый, 0 HP — красный, между ними плавный переход. Здоровье выше
100 окрашивается зелёным. Голубой след — напарник. Ползунок показывает трейс до выбранного
наблюдения, кнопка воспроизведения проходит записи с интервалом 100 мс при 1×.
Это воспроизведение наблюдений, а не точного времени сервера.
Колесо мыши масштабирует карту, перетаскивание перемещает её.
В карточке кадра видны XYZ, здоровье, цель и причина ограничения движения.
При наведении в пределах 10 пикселей от наблюдения на видимой части следа
показывается карточка этого момента: кадр, здоровье, броня, оружие, боезапас,
XYZ, скорость, состояние движения, цель и причина ограничения. Недостающие
поля обозначаются прочерком. При совпадении координат выбирается последнее
наблюдение; ползунок помогает различать моменты в одной точке.
След разрывается при смене соединения, spawncount, сбросе кадра или скачке
более 512 единиц. Такие скачки не входят в длину пути XY.

Схема — проекция направленных вверх поверхностей BSP (нормаль Z >= 0.5),
в исходных мировых координатах. Это статическая схема пола, а не текстурированный
рендер и не состояние движущихся дверей. Этажи накладываются; «Срез по Z»
показывает поверхности и точки в заданном диапазоне высот. Начальная высота —
Z бота минус 24 (приблизительная высота пола). При отсутствии BSP остаётся трейс
и явное сообщение об отсутствии схемы.

Свои каталоги через CLI:

```bat
workspace\build\q2runs.exe -listen 127.0.0.1:18791 -runs workspace\artifacts -assets "..\assets\baseq2;D:\maps"
```

Сервер по умолчанию слушает только loopback. Каталоги `-assets` могут содержать
PAK, подкаталог `maps` с BSP или BSP непосредственно.

Схемы BSP, готовые SVG/JSON и их gzip-версии кэшируются в памяти сервера.
При запуске и каждые 10 секунд сервер обнаруживает карты на диске и прогревает
кэш. Запрос проверяет размер и время изменения исходных BSP/PAK: новая или
изменённая карта подхватывается сразу, без перезапуска. Неизменённая схема
повторно не разбирается и не сериализуется. ETag позволяет браузеру получать
304 вместо повторной передачи схемы; заголовок `X-Map-Cache` показывает HIT/MISS.
Кэш живёт до завершения сервера.

Интерфейс загружает `/api/map.svg?name=base1` и хранит разобранный SVG в кэше
браузера. При масштабировании и перемещении меняется только transform группы
SVG, полигоны не создаются заново. Срез по Z меняет видимость полигонов.
Трейс, отметки и наведение остаются в прозрачном canvas поверх SVG.

Страница занимает высоту окна без вертикальной прокрутки документа.
Список прогонов прокручивается внутри таблицы; карта, ползунок и карточки
остаются в пределах экрана, включая узкие мобильные окна.

Проверки: `go test ./...`; тесты API покрывают пагинацию, поиск, сортировку,
запрет чтения незарегистрированных путей и незавершённый JSONL. Тест BSP проверяет
координаты проекции и отказ на повреждённых индексах.
