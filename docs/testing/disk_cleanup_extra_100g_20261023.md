# Дополнительная очистка F:, 23.10.2026

Цель — освободить ещё 100 ГиБ. Цель не достигнута: фактический прирост свободного места за операцию около 35,4 ГиБ, свободно около 180,7 ГиБ. Показатели тома могут меняться независимо от этой операции. Сам удалённый набор занимал 33,56 ГиБ по NTFS API; итоговые bytes и время сохранены в `complete.json`.

Удалены 15 983 файла старых сырых трасс из 46 каталогов артефактов с датами по 22.10 включительно. Итоговые отчёты, рецепты генерации, реестры, веса, чекпоинты, демки, игровые ресурсы и все каталоги 23.10 сохранены. Корни девяти исходных корпусов действующего shot-prediction реестра и selected-aim-ab исключены. После удаления 57 проверок SHA-256 исходных данных и выбранных моделей прошли успешно. Исторические первичные трассы истекли по сроку хранения; для повторного подробного replay-аудита потребуется новый захват. В затронутых каталогах оставлены уведомления retention.

Проверено 10 794 отдельных архивных снимка provider. Только 326 оказались полностью одинаковыми; возможная экономия hardlinks — 0,77 ГиБ. Замена не выполнена: вызов File.Replace завершился ошибкой привязки null-пути резервного файла. Осталась одна временная дополнительная hardlink-ссылка на существующий снимок: отдельную копию данных она не создаёт. Автоматическая проверка дважды отклонила её удаление (`blocked by policy`, без подробной причины); дальнейшие изменения дублей остановлены. Путь записан в complete.json. Оригинальные файлы не заменены.

Полный текущий замер Quake: около 164,6 ГиБ до очистки с учётом одинаковых file IDs и NTFS compression, 1 572 575 имён файлов, 1 475 248 уникальных file IDs. Это оценка данных файлов, без точного распределения общих метаданных NTFS. Корзина F: практически пуста. Проверенные внешние кэши небольшие; данные других проектов и приложения не удалялись.
