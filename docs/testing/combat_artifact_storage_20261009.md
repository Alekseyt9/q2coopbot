## Сжатие

Схема и логическое содержимое остаются UTF-8 JSONL. Физическое хранение завершённых потоков — Windows WOF LZX через `compact.exe /C /EXE:LZX /F`. Windows прозрачно распаковывает обычные чтения; имена файлов и SHA логического содержимого сохраняются. Это не новая схема бинарных тензоров и не `.gz` архивы, требующие другого reader. Копирование распакованного потока на другую файловую систему может вернуть исходный объём.

Каталог `workspace/artifacts` также помечен для наследуемого сжатия NTFS во время записи. После закрытия завершённого боя `run_learned_combat_baseline.ps1` вызывает `compress_completed_combat_streams.ps1`. Зарегистрированное обучение и architecture processing сжимают закрытые exports перед CUDA update. Проверка процессов защищает от сжатия работающих writers/exporters в выбранном каталоге. Математика policy, reward и physics не изменены.

Сжатие существующих потоков завершено в 4 workers: `compact_combat_artifacts.ps1 -Apply -LzxStreams`. Обработаны 1833 каталога верхнего уровня; все compact workers завершились с exit code 0. Итоговые receipts: `workspace/build/artifact-maintenance/compression-results-20261009-112228.json` и `artifact-maintenance-20261009-112228.json`. Первое стандартное NTFS-сжатие было частичным; затем обработка завершена сильным LZX.

Повторная очистка cache и сжатие при отсутствии активных captures/trainers:

```powershell
scripts/compact_combat_artifacts.ps1 -Apply -PruneExports -LzxStreams -CompressionWorkers 4
```
