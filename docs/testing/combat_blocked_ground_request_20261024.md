## Реализованная отдельная награда v14

`scripts/scenarios/combat-reward-blocked-ground-request-v14.json` сохраняет все коэффициенты v13 и nonterminal handoff. Единственное дополнение — `blocked_ground_request: -0.01`.

Штраф применяется один раз за переход только при всех условиях:

- бот на земле, запрошен vertical=release;
- длина запроса forward/side ≥0.25;
- длина применённого движения <0.1;
- есть movement intervention `static_hull_blocked` либо `static_hull_component_clipped`.

Прыжки, приседание, воздух, no_ground_support, динамические двери, маленькие запросы и сохранённая заметная компонента движения исключены. Стояние само по себе не штрафуется. Проверки геометрии и применение команд не изменены; скрытое состояние не добавлено в observation. Коэффициент выбран как малая стоимость неудачного запроса, равная стоимости off_target_attack; это гипотеза, а не настроенный по validation оптимум. Нулевой коэффициент разрешён для контроля.

Реализация: `internal/learningenv/blocked_ground_request_reward.go`, наследование v13 в `reward.go`. Старые версии не допускают новый ненулевой коэффициент. v14 сохраняет target commitment, sequence context и native hitscan evidence; изменение reward SHA должно оформляться отдельной миграцией checkpoint перед обучением.
