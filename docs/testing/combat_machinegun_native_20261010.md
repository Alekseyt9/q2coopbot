# Нативная диагностика автомата

Добавлена серверная запись `sv_test_hitscan ... g_test_hitscan version=1`
для выстрелов игрока с MOD_MACHINEGUN, только при g_test_damage.
Она содержит рассчитанные игрой start/aim, view/kick angles, скорость,
фактический и номинальный разброс, воду, блокировку ствола, конечный trace,
цель, health_before и состояние оружия. Запись выполняется до T_Damage
и до трасс пузырькового следа. Новые RNG и collision queries не добавлялись.
Побитное равенство двух игровых симуляций отдельно не проверялось.

Shot IDs используют общий diagnostic serial; ID бластера могут иметь
пропуски. Привязка бластера сохраняется. Автомат не меняет g_test_shot_id
игрока: урон связывается по порядку логов, точному native command window,
поколению, кадру сервера, actor/inflictor, цели и health_before.
Нативная диагностика не входит в наблюдения модели или обучающий корпус.

q2ded и game.dll успешно пересобраны CMake/Ninja. Живой smoke:32/32 валидных
записи, четыре семейства × четыре seed × parent3/rules,16 инстансов ×2.
Использованы train132..135: parasite-machinegun-recoil,
parasite-gunner-machinegun-recoil, campaign-base1-site-02-machinegun,
campaign-base2-site-02-machinegun. PPO update3 заморожена, стохастическая.
Это диагностика на train, не независимая оценка превосходства или обучение.

с нативным уменьшением здоровья, включая смертельный выстрел. Это не
точность по выбранной моделью цели.

Это описательная связь: дистанция, цель, длительность боя и движение не
уравнены. Причина ещё не доказана. Далее сопоставить направление до/после
отдачи с доступной клиенту выбранной целью, отделить компенсацию отдачи
от ошибки наведения и закрытой линии огня. Затем менять общие признаки
и GPU-обучение для всех архитектур; parent3 остаётся контрольной моделью.

сверено с view+kick для всех записей. Хэши q2ded/game.dll всех32 runtime
совпали с новой сборкой; source/member proofs прошли. Отчёт бластера после
