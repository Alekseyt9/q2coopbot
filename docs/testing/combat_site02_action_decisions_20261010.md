наблюдаемым решением, не установленной причиной поражения.

`internal/policy/ppo.go` выбирает attack в deterministic режиме по знаку
выхода4 и vertical по argmax. В stochastic режиме используются исходные
Bernoulli/categorical распределения и непрерывные действия с обученным std.
PPO собирает собственные stochastic траектории, тогда как development
оценивалась deterministic. Это основание проверить режим исполнения;
это ещё не доказательство преимущества stochastic политики.
