# Сверка траектории ручной гранаты

Декодер записывает видимые серверные сущности grenade2 в поле projectiles трассы. Это наблюдение текущего snapshot, без сохранения пропавших гранат. Владелец и остаток fuse из модели сущности неизвестны.

Полный изолированный native тест с lifecycle, здоровьем обоих клиентов и калибровкой:

```powershell
./scripts/run_armed_grenade_suite.ps1 -Port 30640 -Parallelism 2 -Repetitions 2
```

Сверка сохранённой трассы:

```powershell
go run ./cmd/q2grenade-report -trace <bot-trace.jsonl> -root <runtime/baseq2> -map base1 -out <calibration.json>
```

Анализатор предназначен для одного native броска без врагов и динамических столкновений. Он требует последовательные серверные кадры одного ID на одной карте, оценивает скорость по первым пяти свободным наблюдениям и затем прогнозирует путь без подгонки по дальнейшим данным. Pmove gravity используется как вход; соответствие sv_gravity является условием постановки. Учитывается вертикальное ускорение при оценке текущей скорости. Радиус погрешности из округления координат до1/8 —0.3125 units/s на ось.

Принимаются минимум8 дальнейших точек, минимум3 после прогнозируемого отскока и ошибка каждой точки<=4 units. Начальные точки не входят в ошибку приёмки. Отдельно сохраняются predicted/observed, ошибка, frame и число прогнозируемых отскоков. Эта проверка не использует исчезновение сущности как доказательство взрыва.

Принято: workspace/artifacts/armed-grenade-suite-20261001-145538-017/report.json,2/2 на2x. В каждом24 контрольные точки,15 после отскоков, max_error0.85/0.93. Lifecycle подтверждает расход одной гранаты и HP100 у обоих клиентов.6 отрицательных контролей отвергнуты. Предыдущая двухточечная оценка в серии145156 дала ошибку22.645 после нескольких столкновений; её результат отклонён и сохранён.

Остаются: предсказание начального импульса до выпуска (hand/fuse/speed/jitter), таймер и подтверждённое событие взрыва, ранний контакт с живой целью, движущиеся цели/напарники, динамические поверхности и безопасный выбор направления. Автоматическая подготовка гранаты пока запрещена.

## Проверка выпуска и настоящего взрыва (01.10.2026)

Анализатор дополнительно требует gunframe10->11 и12->13, выводит timer/speed из native цикла, сопоставляет начальный импульс с допустимым jitter и координату первого tick с center-hand источником. ConnectRequest использует hand=2; прежний диагностический right-hand offset исправлен.

В трассе сохраняются temporary explosion events. Без отдельного события исчезновение гранаты не подтверждает взрыв. Требуется один TE вида7/8/17/18, срок в пределах одного tick и позиция в16 units от последней физической координаты. Визуальная позиция сдвинута относительно физической origin на-0.02*velocity; событие не содержит projectile/owner ID. Поэтому проверка допустима только для изолированной постановки с одним источником взрыва.

Принято armed-grenade-suite-20261001-150454-806:2/2 на2x, arm152, launch155, timer2.9, speed413, native explosion184.6 отрицательных контролей отвергнуты. Подтверждён обычный fuse; ранний взрыв при контакте с живой целью и безопасность движущегося напарника остаются следующими проверками. Автоматическая подготовка гранаты не разрешена.

## Ранний контакт с живой целью

```powershell
./scripts/run_armed_grenade_suite.ps1 -Contact -Port 30690 -Parallelism 2 -Repetitions 2
```

Отдельная base1 постановка содержит две неподвижные hanging misc_insane с нативным здоровьем, без атак. Checker использует их точные fixture bounds из SP_misc_insane; packed solid не передаёт точную асимметричную форму. Требуются пять свободных наблюдений гранаты, неизменные цели и реальный TE взрыва в прогнозируемом contact tick, минимум5 кадров до fuse. Визуальная точка сравнивается с origin-0.02*velocity, предел2 units.

Принято armed-grenade-suite-20261001-153506-724,2/2 на2x: взрыв160 вместо184, ошибка0.04/0.09, оба клиента HP100.6 отрицательных контролей отвергнуты. Обычный fuse регрессии153553:2/2. Это проверка stationary damageable contact, не активного боя или движущегося напарника. Generic arming пока запрещён.
