## Закрытая диагностика исполнения и начального выбора

Все четыре аудита исполнения включают по112 случаев и сверяют прежний порог с ownership для каждого случая. В первых двух восстановленных сетевых кадрах нет видимых врагов под управлением rules и нет отсутствующих применённых действий. Проверены SHA отчётов обработки. Публичный инструмент: `scripts/audit_registered_execution_actions.py`; три теста метаданных проходят с ResourceWarning как ошибкой, сверка реальных восьми случаев совпала с замороженным инструментом эксперимента.

Parent до → после: блокированные attack intents2266→2209, полностью подавленные команды движения4082→3746, завершённые наблюдаемые оружейные запросы100→103. В recovery доля блокированных предложений атаки49,26%→51,76%; снижение абсолютного числа не доказывает улучшения, поскольку эпизоды стали короче. Подавленная команда движения не означает неподвижность тела; attack intent не равен выстрелу.

Отдельная CUDA-проверка восстанавливает собственную полную историю каждой модели, затем измеряет выбор на первом отпущенном сетевом кадре32 recovery-боёв.
