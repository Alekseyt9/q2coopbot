Протоколы: `docs/combat_enemy_threat_predictor_protocol_20261023.json`,
`docs/combat_enemy_hurdle_predictor_protocol_20261023.json`.

Вместо большого плоского прогноза — одна общая сеть для каждого из восьми
наблюдаемых противников, 185→32→16→2, 6514 параметров. Входы: тип, относительная

реально выбранное движение/прицел/огонь и категории действий. Абсолютный yaw
бота убран, собственная скорость переведена в его систему координат. Generic
sin/cos фазы анимации с периодами 4/8/16/32 кадров маскируются при неизвестной
анимации. Отдельный вариант той же ёмкости не получает фазу анимации.

Target — реальный потерянный HP в следующем эксклюзивном native-окне H1,
`min(max(health_before,0),take)`, отдельно по attacker ID и классу в наблюдаемых
enemy slots. Неизвестный/запомненный attacker не приписывается случайному врагу.
TRAIN: 7052 строки / 20 миров, видимый урон 3859 HP, неизвестный 75 HP.
Development: 3055 / 8 миров, 2310 / 37 HP. Четыре прежних counterfactual мира
полностью исключены из fitting/development; их 160 H1 targets равны нулю.
Веса строк учитывают зависимые ветки одного кадра; каждый мир имеет равный вес.
NPZ с атрибуцией занимает 3 683 574 байта.

Два shared варианта обучены по 800 шагов с одинаковыми initialization/batches.
После сохранения обоих endpoints процесс остановился на ошибке имени поля
метаданных gate. Исправлено имя поля; `--seal-only` проверил исходные hashes,
800 шагов, CUDA reload и сохранённые метрики. Добавлено **0 optimizer steps**.

**Изменение следующего шага:** H1 risk полезен как сигнал срочности, но не
доказан как сигнал выбора уклонения: здесь все32реальных H1 causal deltas равны0.
Следующий прогнозатор/teacher должен оценивать хотя бы H5/H10, учитывать
длительность действия и одновременно входящий/исходящий урон. Для fitting
потребуются новые заранее разделённые TRAIN/development миры с реальными
длительными вмешательствами; D5 нельзя объявить освоенным по ordinary/D1 данным.
Эти4audit мира не превращаются в TRAIN. Прежде большого сбора — независимый
pilot нескольких повторов, чтобы отличить эффект движения от случайной
продолженной стрельбы. Рабочий runtime/default остаётся прежним.
