# Автомат и дробовик рядом с напарником — 10.10.2026

В live base2 общий machinegun_partner_guard отменял огонь независимо от
направления. В одном provider window модель начала предлагать attack сразу,
но первый отправленный attack появился через71 frame/7.1 секунды.

## Изолированное исправление

Artifact: `workspace/artifacts/coop-hitscan-guard-fix-v1-20261010`.
Копируются только489 Go исходников, go.mod и малый embedded chktbl.hex;
игровые assets/PAK/AAS не копируются. Основные Go исходники проверены по
source-baseline.json и пока не менялись: параллельный evaluation завершается
со старой версией guard. Candidate files закреплены pending-change.json.

Вместо общего запрета используется пересечение возможного сектора hitscan
с расширенной сферой тела напарника. Компоненты движения, прицел и выбор
оружия не меняются, новые выстрелы не добавляются. Ограничение только
отменяет предложенный огонь при риске.

Native MG spread300/500, новый yaw kick±0.7°, coop pitch kick0..-13.5°.
Скрытый machinegun_shots не угадывается по предыдущему kick: сектор покрывает
весь диапазон. Stock player Shotgun_Fire использует500/500;1000/500 из
DEFAULT_SHOTGUN — не параметры данного player вызова.

Вода может добавить второй разброс2× после первой траектории; сектор
покрывает сумму двух максимальных углов и длин. Поэтому диапазон защиты
не ограничен1024 центрального луча и учитывает возможные два native сегмента
по8192. Для разрешения огня препятствия не используются: центральная стена
не доказывает, что край разброса не проходит сбоку.

Радиус содержит player bbox, muzzle offset8 вправо/8 вниз, квантование,
перемещение обоих игроков за время команды (не менее100мс). Для бота
используется максимум текущей скорости и600units/s; для напарника600.
Свежая наблюдаемая позиция заменяет старую. Недавно исчезнувшая позиция
age0..10frames расширяет радиус на60units/frame. Политика игнорирования
позиции старше10frames сохранена; безопасность для ненаблюдаемых игроков,
произвольно большой задержки и большей скорости напарника не доказана.

## Проверки

Geometry-only `go test ./internal/bot -run '^TestHitscanFriend' -count=1` в
изолированном source прошёл. Neural inference/численные CPU NN проверки
не запускались. Geometry-tests.jsonl сохранён в artifact.

Проверены напарник сзади и сбоку, возле muzzle, на центральной траектории
дальше1024, внутри разброса вне центрального луча, продолжение через воду,
вертикальное разделение, delta yaw, command yaw, свежая/старая позиция и
интеграция с реальным guardDirectCombat на base1 BSP.

Дополнительно4320 независимых native path samples: экстремумы recoil,
углы прицела, углы/corners spread и второй water сегмент. Напарник помещён
на соответствующую траекторию; все варианты запрещены новой проверкой.
Это выборочная геометрическая проверка, не формальная полнота всех float
траекторий и не испытание native friendly fire.

Replay активного префикса живой stochastic записи, только provider snapshots:
из516 прежних MG отмен371 остаются,145 снимаются. Это counterfactual
применение нового guard к старым предложенным командам, без симуляции
последующих кадров. Оно не доказывает145 новых выстрелов или отсутствие
урона в реальной игре.

Осталось: после полного закрытия560 evaluation применить изменение,
повторить целевые geometry regression tests в основном checkout, провести
native сценарий с двумя клиентами на безопасных/опасных расположениях,
проверяя actual shots/damage и отсутствие урона напарнику в принятой сцене.
Живой сервер и бот с человеком не перезапускались; human client закрыт.
