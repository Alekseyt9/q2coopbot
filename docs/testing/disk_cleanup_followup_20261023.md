# Повторная очистка диска, 23.10.2026

Запрос — освободить ещё 100 ГБ. Фактически освобождено **32,72 ГиБ**, свободное место F: выросло примерно с **179,56 до 212,28 ГиБ**. Цель 100 ГБ не достигнута. Другие проекты, установленные программы и пользовательские загрузки не удалялись.

Удалены 32 889 файлов. По NTFS allocated size состав набора:

| Категория | ГиБ |
|---|---:|
| Старые provider snapshots — наблюдения отдельных боёв | 23,003 |
| Служебные сохранения завершённых игровых прогонов | 4,523 |
| Старые сгенерированные исполняемые файлы | 3,982 |
| Старые логи runtime | 0,745 |
| Воспроизводимые кэши Go/Python/npm | 0,485 |

Это истечение хранения старых служебных данных, не обещание обратимого удаления. Для некоторых исторических подробных replay-проверок потребуются новые захваты и сборка утилит. Итоговые отчёты и рецепты сохранены. В затронутых artifact roots оставлены уведомления `service-data-retention-20261023.json`.

Сохранены веса и чекпоинты всех моделей, демки, исходники, конфигурации, реестры, игровые ресурсы, все артефакты 23.10 и защищённые корни действующих исходных корпусов. CUDA streams и части восстановления старых merged caches в набор удаления не включались. Контрольные суммы 86 сохраняемых файлов совпали до и после очистки; среди них исходные корпуса, актуальные веса/чекпоинты и новые predictor/dataset artifacts.

Полный просмотр дерева выполнен заново. Сумма логических размеров включает общие hardlinks и NTFS compression и не равна освобождаемому месту. PAK pool использует отдельные shards из-за предела NTFS в 1024 hardlinks; удаление только имён anchors не гарантирует освобождения данных. Ресурсы PAK/AAS не удалялись. Оставшиеся данные нельзя целиком считать ненужными ради достижения круглой цифры.

Удаление ограничено явными путями внутри `workspace`, без рекурсивного удаления каталогов. Проверялись размер, время изменения, отсутствие reparse ancestors и принадлежность набору. Отбор исключал многоссылочные файлы. После диагностической остановки журнал восстановлен с сохранением исходных bytes; повторное выполнение пропустило уже удалённые записи. Финальная сверка проверила точное соответствие 32 889 записей плану и отсутствие удалённых файлов.

Аудит: `workspace/artifacts/disk-cleanup-followup-20261023/`: `plan.json`, `receipt.jsonl`, `complete.json`, `verification-before.json`, `verification-after.json`, исходный прерванный журнал. Нейронное обучение и inference не запускались; игровые процессы не прерывались. Коммиты и push не выполнялись.
