## Обнаруженная граница наблюдений

Клиентский `quake.Snapshot` содержит `CollisionBodies`, `Obstacles` и `Defeated` (`internal/quake/decode.go`). Это данные сетевых сущностей/наблюдаемых анимаций, без server health. Но `policy.Observation` не имеет отдельных текущих body/corpse полей (`internal/policy/contract.go`). `EnrichEnvironment` делает local probes по статическому BSP и передаёт `Props` только из `s.Barrels` (`internal/policy/environment.go`). Существующие history/remembered threats не эквивалентны отдельному актуальному описанию тел.

Это установленный пробел явного интерфейса, но ещё не доказательство причины197 corpse-перекрытий: надо проверить, какие именно тела действительно были доступны в соответствующем клиентском кадре, с каким solid/model/animation. Нельзя считать native bbox клиентским знанием, если протокол его не передал. Solid0/отсутствие записи должны сохранять маску неизвестности, а не получать выдуманный server bbox.

## Следующее действие

1. Связать corpse contacts этих TRAIN окон с исходным клиентским snapshot того же frame/generation. Посчитать наличие blocker ID в Defeated/CollisionBodies/Obstacles и фактических полях наблюдения policy; определить доступную информацию до команды.
2. Если доступность подтверждается, отдельно спроектировать версионированный вход динамических тел/огневого перекрытия с масками неизвестного. Сохранить старые модели и запретить смешивание старой/новой схемы; принятие решения об огне/цели остаётся у модели.
3. Проверить новую геометрию входа на записанных кадрах и только затем выполнять CUDA перенос/обучение с равным бюджетом и свежими on-policy TRAIN боями. Это не ручной запрет выстрела в труп и не подмена прицела правилами.
4. Для ошибок луча мимо bbox отдельно проверить путь уже обученного sampled-motion/geometry scorer: в текущем source `sampled_motion_aim` всё ещёv1, а не принятый vertical-v2. Предыдущие отрицательные center/vertical/near-identity опыты сохраняются; новое обучение требует конкретного отличия механизма и заранее заданного контроля.

Общее превосходство над rules и устранение лишних действий не достигнуты. Ни этот отчёт, ни корректная физическая реконструкция не являются основанием promotion.
