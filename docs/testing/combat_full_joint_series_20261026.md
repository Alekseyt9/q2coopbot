# Проверка серийного продолжения CUDA PPO

26.10.2026. Добавлен `scripts/run_combat_full_joint_series.py`: существующий native pool на 16 инстансов, x2, отдельный seed на бой, native экспорт без Go NN-проверки, независимый CUDA replay и продолжение полного PPO checkpoint с Adam/RNG. Параметры сети и награда остаются прежними; исходные и рабочие веса не заменяются автоматически.

Серийный запуск требует запечатанный источник: hashes весов/checkpoint/report, совместимый scope и конфигурацию. Он проверяет уникальность семян до игры, полноту каждой партии, source unchanged, CUDA receipts, цепочку использованных rollout и parent checkpoint. Исходники Go/Python/PowerShell, registry и engine привязаны по SHA. Для каждой внешней фазы сохраняются PID, команда, журнал и фактический exit code. Неполная партия не фильтруется по исходам; ошибка останавливает цепочку. Есть резерв свободного места, по умолчанию 32 GiB. Отметка на диске сама по себе не разрешает повторный запуск: перед восстановлением надо проверить живые PID.

CLI запускается из корня `q2coopbot-src`. Новый выходной каталог обязателен. Возобновление остановленной серии выполняется из последнего завершённого `fit` в новом каталоге с последующими свободными seed, после проверки, что старые процессы терминальны. Автоматическое восстановление частично выполненной native-фазы здесь не объявляется проверенным.
