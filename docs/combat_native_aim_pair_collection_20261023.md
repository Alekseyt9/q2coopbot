# Малый сбор native парных меток прицела

Протокол23.10.2026, фиксируется до новых baseline captures. Предыдущая сетка одного TRAIN состояния показала6 полезных поправок из24 принятых, но не доказывает перенос. Новая цель — несколько геометрий и сохранение правильного baseline, а не универсальное повышение частоты поправок.

## Фаза A: свежие исходные траектории

Основа — S после четвёртого near-identity обновления. Диагностическая копия меняет только последний слой aim head: P0=0,999999, положительный равномерный хвост. Actor/value/std/predictor, их Adam/RNG/history сохранены на CUDA; optimizer заменённой головы очищен. Это диагностические веса, без продолжения PPO из подменённого checkpoint.

Существующий registry combat-motor-corpus-preparation-v1:8условий base3/ware2, site01/02, ordinary/recovery. По2свежих TRAIN seeds на условие:16 native и16 CUDA. Выбирается минимальный свободный общий offset не ниже112 по доступной истории планов. Проверяется непересечение seed; недоступные исторические ссылки перечисляются, без ложной гарантии для удалённых артефактов. Skill/оружие/fixtures прежнего реестра, пул до16, ×2, очередь существующего харнеса. Никакого validation, fitting или quality comparison на этой фазе.

## Фаза B: выбрать и повторить небольшие пары

Выбрать4состояния, по одному на каждую пару карта/позиция, по возможности2baseline hit и2baseline solid miss. Отбор целевой и диагностический; это TRAIN, не оценка качества. Моменты должны иметь подтверждённый native MG выстрел, выбранную наблюдаемую цель и валидное exclusive first-life provider window.

Для воспроизводимого первого вмешательства допускаются только eligible frames, где frame-hash gate больше всех предшествующих eligible gates. Константа P0 между предыдущим максимумом и текущим gate обеспечивает category0 до этого момента. До native повторов это проверяется CUDA по историческим Gaussian/discrete draws; фактический префикс затем проверяется отдельно.

Для каждого состояния: baseline и4альтернативы (два лучших ненулевых направления frozen predictor плюс два воспроизводимо выбранных других направления без повторов). Метки берутся из игры, не из predictor. Сохраняются и неудачные прогнозы. Максимум20 native/CUDA на pilot. Если нужная геометрия или баланс отсутствуют, показать доступный состав и ограничение, не скрывать отбор и не расширять сбор автоматически ради хорошего результата.

Приёмка пар: физический префикс с явной стабильной bijection сырых enemy IDs и их ссылок, все остальные observed поля/encoded features/memory/source draws/команды до вмешательства совпадают. В момент вмешательства head timing также совпадает. Несовпадающие примеры исключаются из причинного сравнения и сохраняются как диагностика.

## Граница обучения

Ни baseline, ни альтернативные повторы не объявляются новым обычным on-policy PPO корпусом. Сначала закрыть приёмку сбора и посчитать, есть ли несколько исправимых промахов и случаев сохранения baseline. Затем отдельный протокол GPU supervised fit/расширения TRAIN, с разделением по состояниям/боям/геометрии и контролем только частоты вмешательства. Не делить пять строк одного состояния между train/holdout. Старый validation не становится TRAIN. Default/promotion запрещены в этом сборе.
