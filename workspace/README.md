# Рабочие файлы

`tools/bspc/` содержит отслеживаемые исходники необязательной утилиты AAS. Остальное здесь создаётся локально и исключено из Git:

- `runtime/q2go/` — подготовленный сервер и игровые данные для Go-харнеса;
- `runtime/vanilla/` — прежний диагностический runtime;
- `build/` — Go/CMake-сборки;
- `artifacts/` — трассы, отчёты, журналы и сохранённые старые результаты;
- `tools/dev_tools/` — локальные исторические материалы прежней реконструкции.

В старых документах пути `tools/bspc/`, `dev_tools/`, `build-*` и `artifacts/` могут относиться к структуре до переноса. Новые команды приведены в корневом README.
