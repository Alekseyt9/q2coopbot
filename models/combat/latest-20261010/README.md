# Последние веса моделей боя — 2026-10-10

По одному обученному файлу для каждой архитектуры. Все выбранные обучения выполнены на CUDA. Файлы скопированы без изменения; SHA-256 и происхождение указаны в `manifest.json`.

| Файл | Архитектура | Последнее обучение | Размер, МиБ |
| --- | --- | --- | ---: |
| `mlp64.weights.json` | mlp64 | BC | 4.166 |
| `attention64.weights.json` | attention64 | PPO | 4.402 |
| `attention128.weights.json` | attention128 | BC | 13.200 |
| `gru128.weights.json` | gru128 | BC | 15.411 |

Для MLP64, Attention128 и GRU128 выбран первый сид последнего завершённого общего BC-эксперимента (m0/m2/m3, 500 эпох). Для Attention64 выбран последний завершённый PPO update 4. Это разные истории обучения; набор не является равным сравнением архитектур.

Новизна весов не означает лучшее качество или готовность к замене правил. Для оценки нужны результаты живых боёв.

Это экспорт для инференса в существующем Go-провайдере. Для точного возобновления обучения нужны исходные `checkpoint.pt` с состоянием оптимизатора; они остаются в локальных каталогах обучения и в этот набор не включены. Игровые ресурсы и данные прогонов не включены.

Архив содержит те же четыре файла, README и manifest. Папка находится вне игнорируемого `workspace/artifacts`; коммит и отправка не выполнены.
