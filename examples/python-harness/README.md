# Архивный Python-харнес

Здесь сохранены прежний UDP-клиент, контроллер OpenJev, отчёты и тесты как примеры протокола и сценариев. Их runtime-сценарии зависят от старого Gladiator-мода и не входят в основную Go-сборку.

Локальные тесты без сервера:

```powershell
python -m unittest discover -s examples/python-harness/tests
```

Историческая инструкция: [q2_client_harness.md](../../docs/testing/q2_client_harness.md).
